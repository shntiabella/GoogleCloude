Compute Engine

Highlight produk

  • Cara memilih dan men-deploy VM pertama Anda
  • Mengenkripsi data sensitif dengan Confidential VMs
  • Sesuaikan VM untuk performa, biaya, dan lain-lain

Konfigurasi kustom dan preset

Deploy aplikasi dalam hitungan menit dengan sampel bawaan yang disebut Solusi Praktis. Buat situs dinamis, VM dengan load balancing, aplikasi web tiga tingkat, atau aplikasi web e-commerce.

Pilih dari jenis, ukuran, dan konfigurasi mesin yang telah ditetapkan untuk workload apa pun, dari aplikasi perusahaan besar hingga workload modern (seperti container) atau project AI/ML yang memerlukan GPU dan TPU.

Untuk fleksibilitas lebih besar, buat jenis mesin kustom antara 1 hingga 96 vCPU dengan memori hingga 8,0 GB per core. Dan manfaatkan salah satu dari banyak opsi block storage, mulai dari Persistent Disk yang fleksibel hingga SSD Lokal berperforma tinggi dan berlatensi rendah.

Keandalan terdepan di industri

Compute Engine menawarkan SLA ketersediaan komputasi instance tunggal terbaik dari penyedia cloud mana pun: ketersediaan 99,95% untuk VM yang dioptimalkan untuk memori dan 99,9% untuk semua kelompok VM lainnya.

Apakah periode nonaktif membuat Anda terjaga di malam hari? Pertahankan kontinuitas workload selama peristiwa yang direncanakan dan tidak direncanakan dengan migrasi langsung. Saat VM berhenti berfungsi, Compute Engine akan melakukan migrasi langsung ke host lain di zona yang sama.

Otomatisasi dan rekomendasi untuk efisiensi resource

Menambahkan VM secara otomatis untuk menangani beban puncak dan mengganti instance berperforma buruk dengan grup instance terkelola.

Sesuaikan resource Anda secara manual menggunakan data historis dengan rekomendasi penyesuaian ukuran, atau jaminan kapasitas untuk lonjakan permintaan yang direncanakan dengan pemesanan untuk masa mendatang.

Semua instance komputasi terbaru kami (termasuk C4A, C4, C4D, N4, C3D, X4, dan Z3) berjalan di Titanium, sebuah sistem yang terdiri dari mikrokontroler yang dibuat khusus dan offload penyebaran skala bertingkat untuk meningkatkan performa infrastruktur, pengelolaan siklus proses, dan keamanan Anda.

Harga dan diskon yang transparan

Baca panduan harga mendetail untuk mengetahui jenis atau konfigurasi VM apa pun, atau gunakan kalkulator harga kami untuk mendapatkan estimasi yang dipersonalisasi.

Untuk menghemat tugas batch dan workload yang fault-tolerant, gunakan Spot VM untuk mengurangi tagihan Anda dari 60-91%.

Dapatkan diskon otomatis untuk penggunaan berkelanjutan, atau diskon hingga 70% jika Anda mendaftar diskon abonemen.

Kontrol dan konfigurasi keamanan

Enkripsi data aktif dan saat sedang diproses dengan Confidential VMs.

Bertahan dari rootkit dan bootkit dengan Shielded VM.

Memenuhi standar kepatuhan yang ketat untuk residensi, kedaulatan data, akses, dan enkripsi dengan Assured Workloads.

Manajemen dan observability

Pantau kesehatan dan performa VM secara real-time dengan Cloud Monitoring, dan telusuri log secara terpusat dengan Cloud Logging.

Kelola infrastruktur sebagai kode menggunakan Terraform atau Deployment Manager untuk provisioning yang konsisten dan berulang.

Dapatkan dukungan teknis 24/7 melalui paket Google Cloud Support yang disesuaikan dengan skala bisnis Anda.

Compute Engine adalah layanan komputasi dan hosting yang memungkinkan Anda membuat dan menjalankan virtual machine di infrastruktur Google, setara dengan Amazon EC2 dan Azure Virtual Machine. Tiga cara untuk memulai

  1. Selesaikan tutorial. Pelajari cara men-deploy VM Linux, VM Windows Server, VM yang di-load balance, aplikasi Java, situs khusus, stack LAMP, dan banyak lagi.

  3. Membuat VM dari awal menggunakan Konsol Google Cloud, CLI, API, atau Library Klien seperti C#, Go, dan Java. Gunakan dokumentasi kami untuk panduan langkah demi langkah.

Memigrasikan aplikasi perusahaan

Tiga cara untuk memulai

  1. Selesaikan lab atau tutorial. Dapatkan estimasi cepat biaya migrasi Anda, pelajari cara memigrasikan Linux VM, VMware, server SQL, dan masih banyak lagi.

  3. Ajukan permohonan dukungan migrasi dan modernisasi menyeluruh melalui Rapid Migration and Modernization Program (RaMP) Google Cloud.

Menjalankan aplikasi modern berbasis container

Tiga cara untuk men-deploy container

Container memungkinkan Anda menjalankan aplikasi dengan lebih sedikit dependensi:

  1. Untuk mengelola kontrol penuh atas lingkungan Anda, jalankan image container langsung di Compute Engine
  2. Untuk menyederhanakan tugas pengelolaan cluster dan orkestrasi container, gunakan Google Kubernetes Engine (GKE)
  3. Untuk sepenuhnya menghilangkan kebutuhan akan pengelolaan cluster atau infrastruktur, gunakan Cloud Run
